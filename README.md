## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Comic Tracker** | Track chapter progress with page count and completion status |
| **Brush Library** | Organize saved brushes and sub tools with category tags |
| **Material Manager** | Track downloaded CSP materials with usage and source notes |
| **Story Notes** | Document chapter scripts and panel layout references |
